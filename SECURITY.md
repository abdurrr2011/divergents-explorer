# Security and privacy

The catalogue is a static application without a student-record backend. Local bookmarks and preferences are not an account or a secure place for sensitive information.

Never include credentials or personal student records in an issue, pull request, fixture or screenshot. Use a private maintainer channel for vulnerability reports; use GitHub private vulnerability reporting if enabled after repository creation. Do not post exploitable details publicly.

If a credential is exposed, revoke it through its provider before discussing cleanup. Review both current files and Git history. Changing repository visibility does not change the deployed Site's access policy.
