# Divergents Explorer — source preview 1.0.0-preview.1

A public source snapshot for developer and editorial review. The hosted application remains owner-private.

## Included

- English, Russian and Kazakh browsing, 12 simple interest groups and plain programme names.
- 33 institutions, 54 programmes, 60 admission routes and 146 source records.
- Local shortlist, comparison, intake-aware deadlines and campus photography with provenance.
- Maintenance/schema/research guides, contribution templates, CI and the complete development history.

## Run

Download a GitHub source archive or clone this tag. Use Node.js 22 and Python 3, then run `npm ci`, `npm run check`, `npm start` and open http://localhost:4173.

## Verification and limits

The validation/build pipeline and 69 automated tests pass. Browser visual/authenticated-owner review remains pending. Source claims retain their own cycles and open editorial questions; a source preview is not an admission, funding or diploma-recognition guarantee.

Third-party media/taxonomy licences remain separate. Reuse terms for three source photos covering four institution records remain unconfirmed; see LICENSE.md and docs/PHOTO-CREDITS.md. Public source availability does not supply a general licence for those assets or the application code.

This is a pre-release source snapshot, not a production launch or a desktop installer. No school invitations, application-access change or student-data collection accompanies this release.
