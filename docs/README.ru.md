# Divergents Explorer

Каталог колледжей и университетов для школьников Казахстана. Можно выбирать варианты после 9 или 11 класса, искать программы, сохранять избранное и сравнивать до трёх вариантов.

Интерфейс работает на русском, казахском и английском. Сейчас в каталоге 33 учебных заведения, 54 программы и 60 вариантов поступления. Каталог ещё пополняется: наличие страны или категории в фильтре не означает полное покрытие.

## Запуск

Нужны Node.js 22 и Python 3:

```sh
npm ci
npm run check
npm start
```

Открой http://localhost:4173. Избранное и настройки сохраняются только в текущем браузере.

Исходный код публичный; доступ к самому сайту остаётся приватным. Требования, цены, стипендии и сроки имеют собственные источники и периоды. Неизвестные условия нужно уточнять в учебном заведении.
