# Divergents Explorer

Қазақстан оқушыларына арналған колледждер мен университеттер каталогы. 9 немесе 11-сыныптан кейінгі нұсқаларды қарап, бағдарламаларды іздеуге, таңдаулыларға сақтауға және үш нұсқаға дейін салыстыруға болады.

Интерфейс қазақ, орыс және ағылшын тілдерінде жұмыс істейді. Қазір каталогта 33 оқу орны, 54 бағдарлама және оқуға түсудің 60 нұсқасы бар. Каталог толығып жатыр: сүзгіде елдің не бағыттың болуы толық қамтуды білдірмейді.

## Іске қосу

Node.js 22 және Python 3 қажет:

```sh
npm ci
npm run check
npm start
```

http://localhost:4173 мекенжайын аш. Таңдаулылар мен баптаулар тек осы браузерде сақталады.

Бастапқы код ашық жарияланған, ал сайтқа кіру әзірге жеке қолжетімділікпен шектелген. Қабылдау талаптары, бағалар, стипендиялар мен мерзімдердің өз дереккөздері және кезеңдері бар. Белгісіз шарттарды оқу орнынан нақтылау керек.
